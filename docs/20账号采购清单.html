🌐 四、带宽 / 网络 详细说明

▶ 火山引擎的「带宽」= 弹性公网IP (EIP) 的带宽

  • ECS 本身不自带公网带宽，需单独购买 弹性公网IP (EIP) 并绑定
  • EIP 的带宽 = 你的服务器的公网带宽上限（上行+下行共享）
  • 10 Mbps = 理论下载速度 1.25 MB/s，日均可传输约 ~135 GB
  • VPC 内网通信（ECS ↔ MySQL / Redis / TOS）不占公网带宽、不收流量费
场景走向是否占公网带宽是否收流量费
用户浏览器 → ECS（API 请求） 公网入方向 占带宽（入向免费） 不收（入流量免费）
ECS → 用户浏览器（API 响应） 公网出方向 占带宽 包月已含 / 按量 ¥0.80/GB
ECS → MySQL / Redis VPC 内网 不占 不收
ECS → TOS（读写文件） VPC 内网 不占 不收
ECS → 火山方舟 AI API 公网出方向 占带宽（但数据量小） 极少（文本请求 KB 级）
用户 → TOS 直接下载图片/视频 TOS 公网出 不占 ECS 带宽 TOS 出流量 ¥0.50/GB
用户 → CDN → TOS（配 CDN 后） CDN 边缘 不占 ECS 带宽 CDN 流量 ¥0.21/GB（更便宜）

▶ 带宽选择建议

  • 开服初期（20人）：主服务器 10Mbps + 微服务 5Mbps = ¥230/月 足够
  • 省钱方案：都选 5Mbps（¥150/月），不够再升级（支持在线升配）
  • 上 CLB 后：取消两台 ECS 的独立 EIP，改 CLB 绑定 1 个 EIP + 共享带宽包 15Mbps（~¥200/月，更灵活）
  • 核心原则：媒体文件走 CDN/TOS 直连，不经过 ECS。ECS 带宽只承载 API + WebSocket 数据。

  • 安全组别全放行 — 只开必要端口：22/80/443/4001
