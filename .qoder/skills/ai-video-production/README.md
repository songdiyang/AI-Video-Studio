# AI 视频制作提示词工程体系

> 一套完整的、可独立使用的 AI 视频制作提示词（Prompt）工程模板库。
> 覆盖从剧本到成片的完整流水线，适用于 Seedance、Kling、Runway、Stable Diffusion、DALL·E、Seedream 等主流生成模型。

---

## 这是什么？

本 skill 将一套经过生产环境验证的 AI 视频制作提示词体系封装为**可复用的模板库**。它不是某个特定项目的附属品——拷贝到任何项目、任何 AI 编码工具中即可工作。

## 覆盖的流水线

```
剧本生成 ──→ 智能拆分 ──→ 分镜转化 ──→ 提示词优化 ──→ 运镜设计 ──→ 帧/视频生成
  Markdown   全要素分镜    JSON数组   正/反向提示词   运镜指令     首尾帧/视频
                ↓
         角色白底三视图 ──→ 服装设定图 ──→ 道具设定图
```

每一步都提供了完整的 System Prompt 模板、User Prompt 模板、调用参数建议和输出格式规范。

## 核心能力

| 模块 | 解决的问题 | 关键技术 |
|------|-----------|---------|
| **剧本生成** | 格式混乱、人物世界观缺失 | 结构化 Markdown 输出、前情回顾上下文、场景数量约束 |
| **智能拆分** | 剧本→分镜一步到位 | 6步聚合工作流、角色/场景/道具/影棚全自动提取 |
| **角色白底三视图** | 角色设定图生成 | 白膜标准化着装、设计图/三视图双模式、正面锚定侧面背面 |
| **分镜转化** | 对话与镜头脱节、角色缺失 | JSON 结构化输出、对话→特写、角色数组完整性校验 |
| **提示词优化** | 图片/视频 prompt 质量低 | 情绪叠加理论、五维镜头语言、材质量化描述、正/反向双输出 |
| **运镜设计** | 运镜指令不专业 | 10+运镜技术、情绪-速度映射、镜头衔接逻辑 |
| **帧生成** | 首尾帧差异不明显 | 动作分解冻结、多维度差异约束、单帧防污染 |

## 双轨并行：真人实拍 × 动漫动画

整个体系对真人实拍和动漫动画做了**完整的双轨适配**：

- **真人实拍**：镜头参数（光圈/焦距/快门）、皮肤质感、面料材质、光影物理
- **动漫动画**：赛璐璐/半写实/厚涂风格、色指定、张数密度、分层渲染

每条轨道都有独立的正向提示词维度和反向提示词排除规则。

## 使用方式

### 1. 给 AI 工具用

将 `ai-video-production/` 目录放到任意项目的 `.qoder/skills/` 或对应工具的 skills 目录下即可。

AI 会自动读取 `SKILL.md` 中的模板并应用到生成任务中。

### 2. 给人类参考

直接阅读 `SKILL.md` 了解各步骤的提示词结构和最佳实践；查阅 `templates.md` 获取可直接套用的正向/反向提示词示例。

### 3. 集成到工作流

```
输入：标题 + 风格 + 长度 + 角色设定
  ↓
Step 1: 套用「剧本生成」模板 → 得到结构化剧本
Step 2: 套用「智能拆分」模板 → 得到全要素分镜 JSON（角色服装道具自动提取）
Step 3: 套用「角色白底三视图」模板 → 生成角色设定图
Step 4: 套用「分镜转化」模板 → 得到 JSON 分镜数组
Step 5: 套用「提示词优化」模板 → 得到正/反向 prompt
Step 6: 套用「运镜设计」模板 → 得到运镜指令
Step 7: 套用「帧生成」模板 → 得到首尾帧 prompt
  ↓
输出：传入生图/生视频模型
```

### 4. 单独使用某一步

每个模块都可以独立使用。比如只需要优化现有分镜的 prompt，直接用「提示词优化」部分即可，不需要前面的剧本和分镜步骤。

## 设计原则

1. **模板化而非硬编码**——所有 prompt 使用 `{变量}` 占位，方便替换
2. **System + User 双消息结构**——充分利用模型的指令遵循能力
3. **强制 JSON 输出**——分镜、优化结果均要求结构化输出，便于程序解析
4. **反向提示词必输出**——正向和反向 prompt 成对生成，提高生图/生视频质量
5. **差异化约束**——首尾帧必须多维度有明显差异，避免"两张一样的图"
