🧮 十一、积分公式
积分 = ceil( AI成本 × (1 + 服务费率) ÷ 积分单价 )
积分单价 = ¥0.01  |  服务费率 = 200%（加价倍率 3x） |  充值售价 = ¥0.02/积分
= ceil( AI成本 × 3 ÷ 0.01 ) = ceil( AI成本 × 300 )
示例：图片成本 ¥0.22 × 300 = 66积分  |  视频成本 ¥0.95/秒 × 300 = 285积分/秒
