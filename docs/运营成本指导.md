## 四、成本优化建议

## 六、成本核算公式

### Token 成本换算

```
文本生成成本 = (输入tokens × 2 + 输出tokens × 8) / 1,000,000 元
图片生成成本 = 图片数量 × 0.20 元
视频生成成本 = 视频秒数 × 1.0 元
```

### 项目成本估算模型

```
单项目总成本 = 剧本生成(¥0.03) + 角色图(N×¥0.2) + 分镜图(M×¥0.2) + 视频(S秒×¥1)

示例：10角色 + 30分镜 + 60秒视频
成本 = 0.03 + 10×0.2 + 30×0.2 + 60×1 = ¥68.03
```
